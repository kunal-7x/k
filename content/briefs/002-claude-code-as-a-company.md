# Brief: Run Claude Code like a company (skill crews)

- **Source:** https://www.instagram.com/p/Da0i1JcjXRr/ (@leadgenman — Manthan Patel);
  concept credited to a Norbert Bezzina LinkedIn post.
- **Status:** executed (structure applied to this workspace)
- **Note:** the carousel *images* were rate-limited (Instagram 429 from a
  datacenter IP), so the slide-by-slide visuals weren't captured. This brief is
  built from the post's full caption, which states the concept completely. The
  specific 42-skill list can be re-captured later (retry, or paste the images).

## The play
- **Format:** value carousel (list/framework), strong list-CTA.
- **Hook:** "Stopped treating Claude Code like one assistant and started running
  it like a company."
- **Why it works:** a vivid reframe (AI-as-org) + a concrete, enviable number
  (42 skills, 7 crews) + a keyword DM CTA ("Comment 'SKILLS'"). Curiosity +
  utility + lead capture.
- **The idea:** organize many installable Claude Code **skills** into functional
  **crews** (Developers, Design, Marketing, Finance, Legal, …) inside **one
  workspace** — so the workspace behaves like a company with departments.

## Adapted to us — what we executed
We already have the seed of this: `visual-content`, `content-engine`, the
tracker (`system/track.py`), the 3D `viewer/`. We formalized the workspace into
crews and mapped current + planned skills onto them: **`system/crews.md`** (the
org chart). This directly ties into the tracking system — each crew's skills are
threads in the dashboard.

## Deliverables produced
- `system/crews.md` — the workspace "company" org chart (crews + skills, built vs planned)
- Tracker item for the ongoing build-out (see DASHBOARD)
