## The play
- **Format:** Talking-head to camera + a floating UI mockup overlay + bold
  animated captions ("can now make", "and it builds"). ~22s.
- **Hook (verbatim, on-screen):** the Claude logo → an arrow → a "Design" button
  with a cursor clicking it. Visual promise before a word is spoken.
- **Why it works:** *Novelty + capability reveal.* "You can now do X with a tool
  you already know" triggers curiosity and FOMO. The UI mockup is proof-in-frame;
  the split talking-head keeps a human anchor. The comment-to-get CTA
  ("Comment 'CAROUSEL'") farms engagement, which the algorithm rewards.
- **Structure (beats):**
  1. Visual hook: tool + new feature revealed (0-2s).
  2. Claim: "[Claude] can now make [carousels]" (2-6s).
  3. Proof: show the generated carousel mockup — "No Canva. No templates.
     Just one prompt." (6-14s).
  4. Payoff + CTA: "and it builds… comment 'CAROUSEL' and I'll send it over."
- **CTA / engagement driver:** keyword-in-comments ("CAROUSEL") → DM automation.

## Adapted to our brand
- **Our angle:** same "you can now do X with AI" reveal, pointed at our audience
  of founders/creators who want speed. Lead with the outcome (a finished asset in
  one prompt), not the tool.
- **Our hook:** "You never have to open Canva again." (pattern-interrupt claim)
